# 手动下载 TMDB 身份统一

MP V3 插件，补齐豆瓣、Bangumi 手动下载的 TMDB 主身份转换。订阅继续使用 MP 原生策略。

## 安装

在插件仓库中添加 `https://github.com/hussion/MoviePilot-Plugins-Hussion`，刷新插件市场后安装。安装默认停用；保存启用配置后生效。

## 行为

- 只处理 MP 标记为 Manual 的电影、电视剧下载。
- 使用宿主转换和识别接口；普通转换失败、网络错误、类型或季集冲突均保留原身份继续下载。
- 电视剧要求种子明确标注单季、选集明确、来源与目标季完整集号集合一致；来源无法提供完整集号时保留原身份。多季包、自定义剧集组、需要集号偏移时跳过。
- 不改种子、选集、保存路径，不清理文件、任务或旧历史。
- 详情页保留最近100条结果；停用后停止未来转换。

## 兼容

当前验收范围：MP >=3.2.9,<3.3。下载前媒体对象存在捕获引用，插件完整原位回写已验证的媒体字段。更新 MP 后应先运行宿主数据流回归，不能仅以插件能加载认定兼容。

## 测试

测试应使用与生产一致的 `app.plugins.manualtmdbidentity` 命名空间和 MP 宿主解释器。真实下载与删除测试须单独授权测试媒体。
